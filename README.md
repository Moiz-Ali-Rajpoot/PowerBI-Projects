# 📊 Power BI Projects — Sample Dashboards

A collection of **Power BI dashboards** built for practice and demonstration purposes, covering a range of industries and business domains.

---

## 🗂️ Projects

| Project | Description |
|---|---|
| **Airline Performance** | Flight operations and performance analytics |
| **Contracts & Invoices Dashboards** | RCM contracts and invoice KPI tracking |
| **Employee Analytics** | Workforce overview and payroll insights |
| **HR Analytics** | Human resources metrics and trends |
| **Life Expectancy** | Global health and life expectancy analysis |
| **Medical Billing Credentialing Dashboard** | Credentialing sign-off and submission tracking |
| **Paradise Restaurant** | Restaurant sales and operations analytics |
| **Sales Operations Dashboard** | Sales pipeline and performance tracking |
| **Seattle Construction** | Construction project and cost analytics |

---

## 🛠️ Tools & Technology

| Layer | Tool |
|---|---|
| **Data Source** | Microsoft Excel (.xlsx) |
| **BI & Visualization** | Microsoft Power BI Desktop |

---

> 📌 **Note:** All dashboards use **dummy/sample data** for demonstration purposes only. Real data is not included. Each project folder contains a README with detailed dashboard insights and screenshots.
